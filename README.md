# IssueManager

## Launch instructions
1. Clone repo
2. Generate Github and GitLab personal access tokens
3. Enter tokens into appsettings.json or create your local appsettings
4. Run using IIS Expres (Dockerization in progress 😁)
5. Goto http://localhost/swagger to see endpoints
